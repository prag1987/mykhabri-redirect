# mykhabri-redirect

`mykhabri.in` (बिना www) पर आने वालों को उसी पेज के `https://www.mykhabri.in/...` पर भेजता है।
GitHub Pages पर चलता है; `index.html` और `404.html` एक जैसी हैं ताकि हर path redirect हो।

अस्थायी हल: domain transfer के बाद Cloudflare के 301 Redirect Rule से बदलना है।
